# Security

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/Majkey25/local-camera-wall/security/advisories/new). Include the version, the affected feature, and a minimal reproduction with synthetic data.

Remove camera addresses, credentials, exported backups, and video from reports and attachments. For ordinary bugs, use [GitHub Issues](https://github.com/Majkey25/local-camera-wall/issues).
