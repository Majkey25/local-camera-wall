# Changelog

## 1.1.0

* Added encrypted backup and restore for camera accounts, passwords, and display preferences.
* Added system, light, and dark themes, plus English and Czech language preferences.
* Fixed the size slider while dragging and made all three tile sizes distinct in narrow windows.
* Added Windows build, test, and startup checks and a Windows x64 release ZIP with a SHA-256 checksum.

## 1.0.0

* Added local RTSP playback, a draggable and resizable camera wall, and saved layouts.
* Added local browser pairing and Windows DPAPI protection for saved camera passwords.
